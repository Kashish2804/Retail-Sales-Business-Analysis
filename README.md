# Data Analyst Internship — Project Portfolio

This repository contains all three levels of the Data Analyst internship
project, each in its own self-contained folder with its own README, data,
analysis, and documentation.

## Structure
```
├── Beginner-Level/       Retail Sales & Business Performance Dashboard (Excel)
├── Intermediate-Level/   Superstore Sales Analysis (Python/Pandas)
└── Advanced-Level/       HR Attrition & Workforce Analytics Dashboard (Tableau)
```

## Beginner-Level — Retail Sales & Business Performance Dashboard
Cleaned a raw retail transactions dataset and built a fully formula-driven,
filterable Excel dashboard (KPIs, monthly/category/product/regional/customer
analysis, charts) with evidence-based business insights and recommendations.
**Status: Complete.**
→ [`Beginner-Level/README.md`](./Beginner-Level/README.md)

## Intermediate-Level — Superstore Sales Analysis
End-to-end Python/Pandas analysis of a retail transactions dataset: cleaning,
feature engineering, exploratory analysis, five deep-dive business analyses
(customer behaviour, revenue contribution, product performance, trend
analysis, regional differences), visualizations, insights, and
recommendations — all in a single executed Jupyter notebook.
**Status: Complete.**
→ [`Intermediate-Level/README.md`](./Intermediate-Level/README.md)

## Advanced-Level — HR Attrition & Workforce Analytics Dashboard
An executive-style Tableau dashboard analyzing employee attrition and
workforce health for a mid-size organization: data cleaning pipeline, KPI
catalogue, and insights/recommendations aimed at a CHRO/VP People audience.
**Status: Data, cleaning, KPIs, and insights complete. The built Tableau
workbook (`.twbx`) and walkthrough video are still to be added** — see the
checklist in `Advanced-Level/README.md`.
→ [`Advanced-Level/README.md`](./Advanced-Level/README.md)
